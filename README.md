# Y&B Moda Kids · Protótipo do catálogo digital

Protótipo **visual** do catálogo digital da Y&B Moda Kids, para aprovar o layout e o fluxo de compra.

- **Dados fixos:** é uma cópia dos produtos, sem conexão com o sistema da loja.
  - O estoque só indica disponível, últimas unidades ou esgotado.
  - Os preços e as fotos são de demonstração.
- **Nada é gravado:** a sacola fica no navegador.
- **WhatsApp:** o "pedido" só monta a mensagem. Ela começa avisando que é um teste.
- **O que dá para ver:** início, categorias, busca por palavras-chave, página do produto com fotos que deslizam, sacola, finalizar (retirada ou Uber/99) e a confirmação com a mensagem do WhatsApp.

Para ver no computador, basta abrir o `index.html` ou publicar a pasta em qualquer hospedagem estática.
